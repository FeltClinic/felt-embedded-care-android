TabBarVisibilityManager

class TabBarVisibilityManager

Decides whether your app's tab bar should be visible, from rules set by the web app and by your own code. Reach it through EmbeddedCare.shared.tabBarManager and hide your tab bar whenever isTabBarVisible is false.

Each rule is keyed by a reason. The highest priority rule wins, the newest among equals, and with no rules at all the tab bar is visible.
