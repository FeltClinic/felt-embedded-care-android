PushNotificationPermissionManager

class PushNotificationPermissionManager

Manages push notification permissions for Android

Handles runtime permission requests (Android 13+), permission state tracking, and provides UI for requesting permissions with appropriate messaging.

Reach it through EmbeddedCare.shared.pushNotifications. The SDK configures it during EmbeddedCare.initialize, provided EmbeddedCare.prepareActivity ran in onCreate.

val permissions = EmbeddedCare.shared.pushNotifications
if (permissions.currentState.value == PushNotificationPermissionManager.PermissionState.NOT_DETERMINED) {
    permissions.requestPermissions(PushNotificationPermissionManager.RequestTiming.USER_INITIATED)
}
