EmbeddedCare

class EmbeddedCare

The primary interaction point with Felt's embedded care features

EmbeddedCare is structured as a thin orchestrator that manages specialized manager singletons. Each manager has a focused responsibility:

  • events: SDK event dispatching and subscription

  • badges: Badge state management and polling

  • auth: Account lifecycle and status checking

  • notifications: Push notification token registration

  • experiences: Full screen experience presentation

  • router: Web-to-native event handling

  • tabBarManager: Bottom navigation visibility management
