TabBadgeManager

class TabBadgeManager

Manages automatic badge integration with tab bars for Compose and View-based hosts.

State is exposed as Compose State, so a Compose host observes it by reading it, and a View-based host reads .value directly to get the current value.

// Views
val badgeManager = TabBadgeManager()
badgeManager.syncWithNavigationBar(bottomNavigationView, tabIndex = 1)

// Compose — render your own badge from the observable state
NavigationBarItem(
    icon = {
        BadgedBox(badge = { badgeManager.badgeText.value?.let { Badge { Text(it) } } }) {
            Icon(Icons.Default.Home, contentDescription = null)
        }
    },
    // ...
)
